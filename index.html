Warning

Use it at your own risk. A flash erases all saved scenes and the global settings of the pedal.

If a scene matters to you, write down its settings before you flash.

To go back, flash the official 2.04 file from the Line 6 site.

This page can do that: choose "Back to the official 2.04" in step 1.

1. What do you want to do?

Install: makes the six-pedal mod from your official 2.04 file and flashes it. Back: flashes the official 2.04 file as it is. Both erase all saved scenes and the global settings.

2. Your official 2.04 file

Get the official firmware file M7_BFlash_2_04_00.m9f from https://line6.com/software/ (choose M9, then Firmware). The file is read in this browser only.

Drop the file here, or choose it:

3. MIDI

The browser will ask to control and reprogram your MIDI devices. The page needs this to send the update. Before Flash, the page sends only the version question of "Check the pedal".

4. FLASH UPDATE MODE

  1. Switch the pedal off.
  2. Hold the footswitches 1A and 2A and switch the pedal on.
  3. Keep holding until the display reads FLASH UPDATE MODE and WAITING COMMAND.

In FLASH UPDATE MODE a black overlay covers the display. After the restart, a black residue can stay on the display until the contrast is adjusted.

5. Flash

6. Check the result

After the install path the version is 02M1 (the start-up message reads SIX-PEDAL MOD 1.0). After the way back it is 0204.
